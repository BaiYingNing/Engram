# Engram v1.1.1 Release Notes

## Highlights

- First public open-source release of Engram
- Windows installer package and zip package are now provided
- Local SQLite-based study progress and spaced review workflow
- Built-in CET-6 vocabulary dataset
- Statistics dashboard, theme switching, and desktop-focused study flow

## Included Artifacts

- `Engram-1.1.1-Setup.exe`
- `Engram-1.1.1-win.zip`

## Notes

- Study progress is stored locally on the machine
- The development database file is not included in the repository
- Vocabulary data attribution is documented in the repository README
