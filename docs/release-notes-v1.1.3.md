# Engram v1.1.3 Release Notes

## 更新亮点

- 新增词书切换能力，现已支持 `CET4`、`CET6`、`考研词汇`、`雅思词汇`、`托福词汇` 多词书共存。
- 新增学习数据导出与导入功能，可用于备份、恢复与迁移个人学习记录。
- 数据库结构升级为多词书模式，原有 `1.1.2` 用户升级后会自动迁移旧版数据，并保留已有学习进度。
- 新增正式的 `schema_version` 数据库版本检查机制：启动时只检查数据库结构版本，只有旧版数据库才执行迁移，用户无需担心数据混乱或丢失。
- 新词任务已改为从所有未学新词中随机抽样，修复旧版本“固定从词库前部取词”的问题。
- 设置页新增“词书与数据”分组，并提供更统一的自定义下拉交互。
