# Engram v1.2.0 Release Notes

## 更新亮点

- 新增“学习日刷新时间”设置，可选择每日 `0:00` 或 `5:00` 作为今日统计、每日计划与学习活动的分割边界。
- 单词卡片新增例句展示，优先使用内置词库中的源例句内容。
- 发音系统升级：支持英音 / 美音切换，单词音标前可分别播放英式和美式发音。
- 单词发音优先使用词库音频；在线音频不可用时回退到系统 TTS。
- 对源数据包含 `sSpeech` 的例句，新增例句小喇叭，可播放对应例句音频；无例句音频的数据不会显示按钮。
- 优化主学习界面布局，压缩顶部统计栏与单词区域高度，为释义和例句留出更多阅读空间。

## 数据与兼容性

- 数据库 schema 升级到 `3`，新增单词音频与例句字段。
- 新增 `metadata_sync_version` 元数据标记，用于控制词库音频和例句音频的补齐流程，避免每次启动重复扫描。
- 旧版学习进度会在启动时自动迁移并保留。
- 单词与例句的词库音频依赖在线词典音频接口；无网络或接口不可用时，单词发音会回退到系统 TTS，例句发音不会使用 TTS 兜底。
