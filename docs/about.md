## 关于 Engram

Engram 是一个面向高强度英语词汇记忆场景的桌面应用。

它的设计重点不是游戏化激励，而是尽量减少干扰，让学习流程保持直接、稳定和高频。当前版本采用 Electron + 原生 HTML/CSS/JavaScript + SQLite 的本地架构，默认内置 CET-6 词库，并在本地保存学习进度。

### 设计目标

- 用尽量低摩擦的交互完成大批量过词
- 把新词学习和到期复习放进同一条工作流
- 保持完全本地化，不依赖常驻后端服务
- 让统计和节奏反馈服务于复习，而不是喧宾夺主

### 当前能力

- 单词卡片式学习
- 三档反馈：不认识 / 模糊 / 认识
- 间隔复习调度
- 学习统计面板
- 深浅主题切换
- Windows 桌面打包

### 项目状态

当前仓库公开的是可运行、可继续迭代的版本。后续可能继续完善词书扩展、体验细节、发音控制、导出能力等内容。
