### 简介

Engram 是一款主打 **“激进速通”** 的高强度英语词汇记忆的桌面应用。

它的设计初衷是剥离一切非必要的视觉干扰与游戏化机制，提供一个**极简**、**专注**的终端，让学习流程保持**直接**、**稳定**和**高频**，以应对短期内需要极大量扩充词汇储备的备考需求（如 CET-6 突破、雅思前置准备等）。

当前版本采用 Electron + 原生 HTML/CSS/JavaScript + SQLite 的本地架构，默认内置 CET-6 词库，并在本地保存学习进度。

### 项目亮点

- 单词卡片式学习
- 三档反馈：不认识 / 模糊 / 认识
- 间隔复习调度
- 学习统计面板
- 深浅主题切换
- 用尽量低摩擦的交互完成大批量过词
- 把新词学习和到期复习放进同一条工作流
- 保持完全本地化，不依赖常驻后端服务
- 让统计和节奏反馈服务于复习，而不是喧宾夺主
- Windows 桌面打包

### 核心机制

- **高负荷速通：** 交互逻辑追求**极致精简**，支持全键盘操作。软件架构专为每日**数百词**的高强度、大批量过词策略进行优化，以量取胜，快速建立视觉词汇映射。
- **算法驱动复习：** 系统会动态计算每个单词的记忆阶段与复习间距，确保底层调度严格遵循**艾宾浩斯遗忘曲线**。
- **本地化与数据掌控：** 采用 Electron 架构开发，所有词表、进度与状态数据均封装于本地 SQLite 数据库中。无需联网即可实现**零延迟**的响应速度，确保**最纯粹**、**无干扰**的使用体验。

### 项目状态与演进计划

Engram 的基础记忆闭环已构建完成。作为一款注重实用性的效率工具，后续版本计划实装以下特性：
- **发音引擎扩展：** 增加更灵活的语音控制模块，支持在不同发音风格（英音/美音）之间进行切换，以辅助听力环境的适应。
- **多词库架构：** 开放词书切换功能，允许挂载和管理多套独立词库，满足从六级到更高阶学术英语等不同阶段的备考切换需求。
