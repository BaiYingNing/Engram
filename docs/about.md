### 简介

Engram 是一款主打 **“激进速通”** 的高强度英语词汇记忆的桌面应用。

它的设计初衷是剥离一切非必要的视觉干扰与游戏化机制，提供一个**极简**、**专注**的终端，让学习流程保持**直接**、**稳定**和**高频**，以应对短期内需要极大量扩充词汇储备的备考需求（如 CET-6 突破、雅思前置准备等）。

当前版本采用 Electron + 原生 HTML/CSS/JavaScript + SQLite 的本地架构，内置 CET4、CET6、考研、雅思、托福等多套词书，并在本地保存学习进度。

### 项目亮点

- 单词卡片式学习
- 三档反馈：不认识 / 模糊 / 认识
- 间隔复习调度
- 多词书切换
- 例句展示
- 英音 / 美音播放
- 可选 0 点 / 5 点学习日刷新
- 学习统计面板
- 深浅主题切换
- 用尽量低摩擦的交互完成大批量过词
- 把新词学习和到期复习放进同一条工作流
- 保持完全本地化，不依赖常驻后端服务
- 让统计和节奏反馈服务于复习，而不是喧宾夺主
- Windows 桌面打包

### 核心机制

- **高负荷速通：** 交互逻辑追求**极致精简**，支持全键盘操作。软件架构专为每日**数百词**的高强度、大批量过词策略进行优化，以量取胜，快速建立视觉词汇映射。
- **算法驱动复习：** 系统会动态计算每个单词的记忆阶段与复习间距，确保底层调度严格遵循**艾宾浩斯遗忘曲线**。
- **本地化与数据掌控：** 采用 Electron 架构开发，所有词表、进度与状态数据均封装于本地 SQLite 数据库中。核心学习流程不依赖常驻后端服务；发音能力会优先尝试在线词库音频，必要时回退到系统 TTS。
- **语境与发音辅助：** 单词卡片会展示源词库例句，并支持英音 / 美音播放。若源数据提供例句音频，例句旁也会显示独立播放按钮。

### 项目状态与演进计划

Engram 的基础记忆闭环、多词书架构、例句展示与发音辅助已经构建完成。作为一款注重实用性的效率工具，后续版本会继续围绕学习流畅度、词库质量与数据可控性进行迭代。
